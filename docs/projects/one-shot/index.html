One-Shot Egocentric Robot Learning

Recover task structure from an egocentric demonstration and execute it when the robot scene changes.

Under ReviewReal robot

Overview

An object-centric framework that extracts reusable task structure from an egocentric human demonstration and converts it into robot task-and-motion plans.

How It Works

My Contribution

  • Developed a one-shot framework for extracting object-centric task constraints from an egocentric demonstration.
  • Combined VLM grounding, structured task representations, and task-and-motion planning.
  • Implemented recovery for changed initial poses, displaced objects, and new obstacles.

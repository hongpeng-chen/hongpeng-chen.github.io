GLaMP: Grounded Multimodal Agents

Execute long-horizon manipulation tasks from natural-language instructions without task-specific training.

PublishedReal robot

Overview

A closed-loop manipulation system combining pretrained VLM/LLM reasoning, grounded perception, symbolic skills, and behavior-tree execution.

How It Works

My Contribution

  • Developed the grounded multi-agent planner and PDDL-defined skill library for executable behavior trees.
  • Built the perception–execution stack with Grounding DINO, RGB-D geometry, 6D pose estimation, and AnyGrasp.
  • Integrated VLM verification for closed-loop manipulation and evaluated five physical task scenarios.
